# Règles du projet TechDay

- Le projet se construit dans les pages Web de GitHub, Supabase et Google AI Studio. Pas de terminal ni de modification de fichiers locaux sans demande explicite.
- L'utilisateur fait les actions. L'assistant explique pourquoi et vérifie le résultat avant la suite.
- Conserver le CSV original sans le modifier. Ne pas publier le CSV, les mots de passe ou les clés privées sur GitHub.
- Dans le HTML, seule la clé Supabase « publishable » est autorisée. La clé Gemini reste dans les secrets Supabase.
- Garder l'ancien dépôt GitHub et l'ancien projet Supabase intacts.
- Après chaque étape vérifiée, noter l'avancement dans `docs/JOURNAL.md` et `docs/ROADMAP.md`, puis enregistrer un commit clair.
